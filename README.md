# SearchStack Organizer 取扱説明書

**SearchStack** は、開きすぎたブラウザのタブや検索履歴を意味的にグループ化（スタック化）し、情報過多による「タブ迷子」を防ぐためのスマートブラウザマネージャーです。

---

## 1. 画面構成

画面は大きく3つのエリアに分かれています。

### 📌 左サイドバー（ナビゲーション）
- **表示ビュー**: 「ボード表示」と「タイムライン表示」を切り替えます。
- **ジャンル区分**: 「すべて」「プログラミング」「デザイン」など、保存されたタブをカテゴリごとに絞り込んで表示します。
- **アプリ情報**: 現在の保存タブ数や、スタック（重ねられたグループ）の数が表示されます。

### 📌 メインコンテンツ（中央エリア）
- **トップバー**:
  - 🔍 **検索バー**: キーワード、URL、ページの概要からタブを素早く検索できます。
  - 🌓 **テーマ切り替え**: 太陽/月のアイコンでライトモード・ダークモードを切り替えます。
  - 🔄 **履歴同期**: ブラウザの履歴（またはデモデータ）を読み込みます。
  - 🗂 **類似タブを重ねる**: スイッチをオンにすると、同じテーマのタブが自動でひとまとめにスタックされます。
  - ➕ **新規タブ追加**: 手動で新しいタブ情報を登録できます。
- **表示エリア**: 選択したビュー（ボードまたはタイムライン）でタブの一覧が表示されます。

### 📌 右サイドバー（AI 提案・アシスタント）
- **信頼性の高い過去情報**: 検索キーワードや選択中のカテゴリに応じて、公式ドキュメントなど信頼性が高いと判定された情報が優先的に提案されます。
- **スマートスタックの推奨**: 「類似タブを重ねる」をオフにしている場合などに、ばらばらになっている関連タブをまとめるよう提案してくれます。

---

## 2. 基本的な使い方

### 1️⃣ ビューを切り替える
左サイドバーの「表示ビュー」から、目的に合わせて表示方法を変更できます。
- **ボード表示**: タブをカード形式で並べて表示します。関連タブの「スタック（重ねがけ）」を利用する場合はこちらが便利です。
- **タイムライン（さかのぼり履歴）**: タブを保存・閲覧した時間を軸にして、時系列（カレンダー風）で振り返ることができます。

### 2️⃣ タブをスタックする（重ねる）
関連する検索（例：「Reactのフック」に関する複数の記事など）は、自動的に重ねて表示されます。
- トップバーの **「類似タブを重ねる」** スイッチがオンになっているか確認してください。
- スタックされているカード（「〇〇 重ね」というバッジがついています）をクリックすると、重なっているタブが展開されます。
- 展開された個別のカードをクリックすると、さらに詳細な情報（AI要約など）を見ることができます。

### 3️⃣ 情報を見つける（検索・絞り込み）
- 画面上部の検索バーにキーワードを入れると、即座に該当するタブのみが表示されます。
- 左サイドバーの「ジャンル区分」をクリックすると、「デザイン」や「プログラミング」などのカテゴリでフィルタリングされます。

### 4️⃣ タブの詳細を見る・ブラウザで開く
カードをクリックすると詳細モーダルが開き、以下の確認・操作ができます。
- **AI要約**: ページ内容の「ひと目でわかる概要」
- **情報の信頼性評価**: 星の数による簡易評価
- **実際のブラウザで開く**: リンク先の元ページを開きます
- **タブを削除**: 不要になったタブをリストから削除します

---

## 3. その他の便利機能

### 📝 新規タブの追加（＋ボタン）
自分が今見ているページや、残しておきたい情報を手動で追加できます。「タイトル」「URL」「概要」などを入力して保存すると、AIが自動で「ジャンル」を判定して適切な場所に配置します。

### 🔄 履歴同期（デモ体験）
「履歴同期」ボタンを押すと、自動的に複数の履歴を読み込み、AIによる自動分類・スタック化を一瞬で行うシミュレーションを体験できます。
